Compile a chapter.

Drop a source-chapter PDF. Every pass runs for real — no canned demo data — then open the concept graph, take the quiz, or read the certificate.

Model backend

Maps the strong/cheap tier every pass already asks for to local model tags. Blank uses the defaults (llama3.1 / llama3.2). Needs ollama serve running with those models pulled on the machine running coursec web.

RUNNING 

      

    

  


  

    
What runs

    

      
Ingest → structure
PDF blocks, extracted concepts, a prerequisite DAG — each pass writes only its own columns, enforced at runtime.

      
Evidence → compose
Grounded generation, constrained to a dossier of cited spans. An ungrounded slot refuses before the model is even called.

      
Verify → assess
A citation-blind critic, executed arithmetic, four blocking item gates. See the invariants.

      
Emit
Booklet, cheat sheet, question paper, answer key — or none of them, if any invariant broke. The certificate says why.

    

  







  

    

      § 00  About
      a violation is a build failure — never a warning, never a TODO
    

    

      CourseC treats course generation as compilation, not a single prompt: the source chapter
      is the input language, a typed Concept Graph is the IR, ten independently-tested passes
      transform it, four typeset documents are the code generation step. Every claim carries
      its citation; every number is executed, never written.
    

  


  

    
The seven invariants

    

      
I1
No unsupported sentence.
Every emitted sentence carries a citation and passes entailment against the spans it cites. Unentailed → repair twice → drop → quarantine.

      
I2
Numbers are computed, never generated.
Every numeric literal traces to a span, a cited source, or a sandboxed SymPy result. The model phrases; it never originates a value.

      
I3
Provenance is total.
Every node reachable from a document traces to file or url, locator, retrieval time and content hash.

      
I4
The prerequisite graph is acyclic.
Cycles break by a deterministic, logged policy — lowest confidence first, tie-broken on content hash. Never silently.

      
I5
Contract before emission.
Five slots: definition, intuition, worked example, visual-or-analogy, and two assessment items. A concept enters a document only with its status attached.

      
I6
Contradiction is surfaced, never resolved.
When retrieved evidence disagrees with the source, the source stays primary and the divergence becomes a marked note carrying both citations.

      
I7
Licence-clean media only.
An image is a bbox crop of the source, generated diagram code, or nothing at all.

      
These are not aspirations in a design doc. They are the thing the adversarial suite exists to break — and a gate that never rejects anything is broken, not perfect.

    

  


  

    

      Grounding
      hover a claim — its source lights in the margin
    


    

      

        The critic never sees the dossier that produced the sentence it is grading.
        It sees one sentence and, for each, only that sentence's own cited spans —
        looked up fresh by id.
        A chapter's concepts merge at cosine 0.801,
        every MCQ distractor cites a real misconception node2, and
        twelve simulated students screen each item3
        before it is allowed near a question paper.
      


      

        
Marginalia

        
1 Tuned against a committed labelled fixture: “Ohm's law”/“V = IR” embed at 0.855; the closest false positives, “variance”/“covariance” at 0.764, sit below the line.

        
2 Sourced from sentences the critic actually marked contradicted — real material, never invented. A distractor that can't cite one is dropped.

        
3 Labelled screening, never calibration — twelve students is nowhere near enough for a calibration claim, and the wording is not allowed to drift.

      

    

  


  

    
What comes off the press

    

      
Booklet
Every contract slot, Mermaid visuals rendered at build time, source figures cropped by stored bbox, and a bibliography walked from the citation edges.

      
Cheat sheet
A pure template over each concept's own source span — so it makes zero model calls, asserted on the cache-miss counter.

      
Question paper
Greedy selection against a blueprint of marks, Bloom mix and unit weightage. An infeasible blueprint names its binding constraint.

      
Answer key
Mirrors the paper's selection and reads each numeric item's stored execution result rather than recomputing anything.
